# Concurred 1.0.0

Good things start with a chat. Concurred brings your choice of AI models into a
familiar Mac messaging app, with Cloak to help you share fewer personal details.

## Download

Download **Concurred-macOS.zip**, unzip it, and drag **Concurred.app** to Applications.
Requires macOS 14 or later. One universal app for Apple Silicon and Intel Macs.
Developer ID signed and notarized by Apple.

## In this release

- Chat through OrcaRouter, OpenRouter, Featherless, or Concurred with your own API key.
- Use Alt ID and Cloak to replace personal details before sending. Review outgoing
  text and choose extra phrases to hide with detection running on your Mac.
- Enjoy streaming replies, saved chats, character portraits, Markdown, and simple copying.
- Choose User-Agent presets with animated device previews, or configure a provider proxy.
- Add web search with a separately installed and authenticated TinyFish tool.

## Mac password prompts, explained

Concurred now explains Keychain access before your first key operation. If macOS
offers **Always Allow**, use it to remember access to that provider's key.

Want no Keychain prompts? Choose **Use Local Storage** in the dialog or change
**Settings → API key storage**. Local keys are saved in an unencrypted file on your
Mac. Enter keys again after switching; existing Keychain keys are not copied or
deleted. Keychain remains the default.

Cloak can miss personal details. Review sensitive messages before sending.
Saved chats contain the original text on your Mac.
